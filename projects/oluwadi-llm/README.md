\# Oluwadi — LLM for Land Surveying (RAG Prototype)



Oluwadi is a domain-specific assistant for land survey automation. It will use vector databases

and retrieval-augmented generation (RAG) to provide actionable surveying assistance.



\### 🧭 Use Cases

\- Engineering survey lookup

\- Title \& property info extraction

\- State/National surveying codes knowledge base

\- Step-by-step computed guidance



\### 🔧 Planned Stack

\- LangChain

\- Embeddings + Vector DB (Chroma or FAISS)

\- PDF loaders/model parsing

\- Domain-specific prompting and constraints



\### 🎯 Vision

A deployable AI assistant tailored for contractors, civil engineers, and surveying professionals.
