\# Aircraft Recognition with CNNs (ISR-Oriented Prototype)



This project demonstrates aircraft image classification using CNNs as a proxy for ISR-style recognition tasks.

The model uses transfer learning to identify aircraft classes and explore viability for automated assistance.



\### 🎯 Mission Relevance

\- Potential foundation for ISR automation

\- Demonstrates machine learning under realistic constraints (limited data, imperfect imagery)



\### 🧱 Stack

\- Python, PyTorch

\- Jupyter Notebooks

\- TorchVision Models (ResNet50 or similar)



\### 📊 Output (To Come)

\- Confusion matrix

\- Per-class accuracy table

\- Notes on domain adaptation



This is a \*\*baseline model\*\*, intended for iterative improvement (dataset realism, multi-sensor fusion, YOLO detection + classification, etc.).
