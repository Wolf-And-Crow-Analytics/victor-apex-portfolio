\# Projects



This folder contains applied machine learning, computer vision, and LLM projects focused on

defense, ISR, automation, and intelligence workflow modernization.



Each project includes:

\### 🔧 Technical Implementation

\- Clean code or notebooks

\- Reproducible instructions

\- Documentation of results



\### 🎯 Mission / Operational Context

\- Why this matters for military or intelligence applications

\- Limitations and future pathways for improvement



Projects are organized individually to make cloning and review simple for recruiters, researchers, and leaders.
